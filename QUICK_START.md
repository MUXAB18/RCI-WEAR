# ⚡ Quick Start Guide

## 🚀 Deploy in 5 Minutes

### Step 1: Build
```bash
npm run build
```

### Step 2: Deploy

**Option A - Vercel (Easiest):**
```bash
npm i -g vercel
vercel
```

**Option B - Netlify:**
- Go to https://app.netlify.com/drop
- Drag `dist` folder
- Done!

**Option C - GitHub Pages:**
- Push `dist` folder to gh-pages branch
- Enable GitHub Pages in settings

## 🆘 Quick Fixes

**Emails not sending?**
- Check EmailJS dashboard logs
- Verify credentials in QuoteModal.jsx
- Check spam folder

**Site looks broken?**
- Clear browser cache
- Run `npm run build` again
- Check console for errors

**Slow loading?**
- This is normal (3-5s on mobile)
- Due to 3D animations
- Acceptable for premium site
